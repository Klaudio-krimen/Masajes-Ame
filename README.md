# Âme — Masoterapia y medicina alternativa

Sitio web de **Âme Masoterapia**: presentación de la especialista, catálogo de 10 servicios (relajación, descontracturante, piedras calientes, drenaje linfático, presoterapia, entre otros) y reserva directa por WhatsApp.

🌐 **Sitio:** [masajes-ame.vercel.app](https://masajes-ame.vercel.app)

## Qué incluye

| Página | Contenido |
|---|---|
| `index.html` | Inicio, la especialista, redes sociales y contacto |
| `servicios.html` | Servicios con botón de reserva por WhatsApp y mensaje prellenado |

## Stack

- HTML5 estático, sin build
- Tailwind CSS (CDN), Google Fonts (Montserrat + Playfair Display), Font Awesome
- Deploy en Vercel

## Ver en local

```bash
npx serve .
```
